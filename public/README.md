# Pachkhan Audio Files

The application is configured to play audio files for each Pachkhan type.
Due to copyright and website restrictions (ad-supported redirects), we cannot automatically download these files.

## Instructions to Add Audio

1.  **Download** the audio files from one of the following sources:
    *   [Jain Literature (Weebly)](http://jainliterature.weebly.com/pachakhan-audio.html)
    *   [Lok Dayro App/Website](https://lokdayro.com/)
    *   Or any other source you prefer.

2.  **Rename** the downloaded MP3 files to match the IDs below and place them in this folder (`public/audio/`).

| Pachkhan | Expected Filename |
| :--- | :--- |
| Navkarsi | `navkarsi.mp3` |
| Porsi | `porsi.mp3` |
| Sadh-Porsi | `sadh-porsi.mp3` |
| Purimuddha | `purimuddha.mp3` |
| Avadhdh | `avadhdh.mp3` |
| Upvas | `upvas.mp3` |
| Upvas (Water) | `upvas-water.mp3` |
| Ekasana | `ekasana.mp3` |
| Beasana | `beasana.mp3` |
| Ayambil | `ayambil.mp3` |
| Nivi | `nivi.mp3` |
| Tivihar | `tivihar.mp3` |
| Chauvihar | `chauvihar.mp3` |
| Panahar | `panahar.mp3` |

## Note
If a file is missing, the application will automatically fall back to **Text-to-Speech (TTS)** using the browser's built-in voice.
